# Can we use this?

Content Creator | Hearst | GitHub Pages edition | 4 November 2026

A browser-based activity about copyright, Adobe Express assets and AI images
in behind-the-scenes, event and social content supporting editorial teams.

## Use the files

Extract the ZIP. Upload its contents, keeping `index.html` at the publishing
root and preserving the `images` and `assets` folders. Set GitHub Pages to
serve that folder. No build command, server, account or API key is required.

You can also open `index.html` locally to review the activity. Browser storage
and downloads can behave differently for local files, so review the hosted
version before sharing it with learners.

This edition has no SCORM manifest and makes no LMS API calls.

## What learners do

1. Inspect images and evidence in seven fictional briefs.
2. Choose Use it, Investigate or Replace and explore the feedback.
3. Respond to a fresh final brief, giving a recommendation and three short
   explanations about rights, evidence, approvals and practical next steps.
4. Compare their completed first attempt with an example response if useful.
5. Optionally apply the checks to their own supporting content.
6. Download an Evidence of Learning PDF for saving or tutor submission.

The final task is a written application of learning, not an automatically
marked test. A different decision can be defensible when the learner explains
what must change and why. A practice decision alone does not prove mastery.

The PDF includes the final brief and evidence, the learner's actual decision
and answers, whether the example was viewed, all seven practice decisions,
the optional work application, key guidance and source links. Incomplete final
tasks are labelled Draft. No learner identity is collected automatically.

## Saving and privacy

Progress and written answers save in this browser on this device, subject to
browser settings. They do not automatically reach a tutor or sync across
devices. Downloading the PDF is learner controlled. Do not enter confidential
material or personal information. Start again clears the saved attempt after
confirmation. Earlier local progress from the prior activity is migrated when
it exists on the same origin and browser.

## Images and fictional records

All five scene images were generated specifically for this learning activity.
The book symbol is an original demonstration SVG. Captions and the scope note
explain their actual origin. No image is represented as a real Hearst event,
an Adobe Stock download or a Firefly output. The presenter is fictional.

The case evidence deliberately assigns hypothetical creation records and
licensing conditions. These are learning scenarios, not actual licences for
the supplied files. Learners must judge those records, not try to detect AI
or infer rights from appearance. See IMAGE_NOTES.md for asset details.

## Internal policy and terms

UK-focused guidance with linked primary sources. Fictional approvals are
explicitly labelled and do not assert Hearst policy. Align internal approval
instructions with the organisation's actual AI policy, editorial standards,
permissions processes and Adobe agreement before learner release. No live
licence verification, AI detection or automated legal assessment is performed.

## Accessibility and verification

Includes semantic controls, labelled fields, visible keyboard focus, alt text,
responsive layouts, no hover-only interactions and a fullscreen fallback.

Passed JavaScript syntax, all 21 practice branches, final task and example
comparison, local save/resume, reset, blocked-storage handling, fullscreen
state retention in a simulated document, asset-path checks, draft/completed
PDF generation and visual review of the generated PDF pages.

Live browser layout, keyboard and screen-reader behaviour, mobile PDF handling
and the eventual GitHub-hosted version remain to be checked before release.
Browser automation was unavailable during preparation.

## Dependencies and branding

PDF generation is bundled locally using pdf-lib. Its MIT licence is included
in THIRD_PARTY_LICENSES.txt. The supplied Bauer Academy logo and BauerMedia
Sans are embedded in the finished learning resource. PDF text uses a standard
Helvetica fallback. The interactive does not depend on a CDN.
